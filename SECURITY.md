# Security policy

## Reporting a vulnerability

Please report security problems privately, not in a public issue. Use GitHub's [private vulnerability reporting](https://github.com/Medalink/watcher/security/advisories/new) for this repository, or contact the maintainers through https://medanet.co.

Include what you found, how to reproduce it, and what an attacker could do with it. You will get a reply within a few days, and a fix or a plan for one once the report is confirmed.

## Supported versions

Fixes go into the latest version on `main`.
